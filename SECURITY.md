# Política de segurança

## Versão mantida

Somente o conteúdo do branch `master` e a implantação de produção correspondente recebem
correções de segurança.

## Como reportar

Envie o relato de forma privada para `claudioshema2009@gmail.com` com:

- resumo do problema;
- rota ou componente afetado;
- passos mínimos para reproduzir;
- impacto observado;
- sugestão de correção, quando houver.

Não abra uma issue pública contendo token, dados de cliente, telefone, e-mail de lead ou
detalhes que permitam explorar a falha antes da correção.

## Dados de teste

Nunca use dados pessoais reais para demonstrar uma vulnerabilidade. Utilize nomes,
telefones e e-mails claramente sintéticos e remova qualquer documento temporário ao final.
